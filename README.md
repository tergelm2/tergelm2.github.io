# Tergel Myagmarsaikhan — Portfolio

Source for [tergelm2.github.io](https://tergelm2.github.io), a Jekyll portfolio with project case studies and links to original work.

## Update the site

- Edit the introduction in `_includes/landing.html` and the bio in `pages/about.md`.
- Add or revise case studies in `_projects/`. Project illustrations live in `assets/projects/`.
- Edit `assets/css/style.scss` for styling, then regenerate `assets/css/style.css` with Sass.
- Run `bundle install` and `bundle exec jekyll serve` to preview locally.
- Push source changes to `main`; GitHub Pages builds the site from the repository root.
- Generated output (`_site/` and Sass caches) is ignored; do not commit it.

The original course template was based on [portfolYOU](https://github.com/YoussefRaafatNasry/portfolYOU) and [4dcu.be](https://github.com/4dcu-be/4dcu.be). Their credits and licenses remain in the repository.
